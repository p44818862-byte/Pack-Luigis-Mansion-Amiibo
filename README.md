# Pack Luigi's Mansion + Amiibos

Ce pack contient le jeu **Luigi's Mansion** pour émulateur ainsi qu'une sélection de fichiers **Amiibo (.bin)** compatibles pour enrichir votre expérience de jeu.

## 📦 Contenu du Pack

* **Jeu :** `Luigi's Mansion (Europe) (En,Fr,De,Es,It).3ds`
* **Amiibos inclus :**
  * `[SM] 01 - Mario.bin`
  * `[SM] 03 - Toad.bin`
  * `[SM] 04 - Luigi.bin`
  * `[SM] 04 - Luigi [Special Data].bin`
  * `[SM] 15 - Boo.bin`

---

## 🛠️ Comment installer et extraire le pack ?

Le jeu dépassant la limite de taille de GitHub, l'archive a été découpée en plusieurs morceaux (fichiers `.001`, `.002`, etc.). Suivez ces étapes pour reconstituer le pack :

### 💻 Sur Ordinateur (Windows / Mac)
1. Téléchargez **tous les fichiers de l'archive** présents sur ce dépôt GitHub dans le même dossier sur votre ordinateur.
2. Téléchargez et installez le logiciel gratuit [7-Zip](https://7-zip.org) (Windows) ou [Keka](https://keka.io) (Mac).
3. Faites un clic droit sur le **premier fichier uniquement** (celui qui se termine par `.001` ou `.zip.001`).
4. Choisissez **7-Zip** > **Extraire ici**. Le logiciel va automatiquement rassembler tous les morceaux pour recréer le dossier complet.

### 📱 Sur Android
1. Téléchargez tous les fichiers de l'archive dans le même dossier sur votre téléphone.
2. Installez l'application gratuite **ZArchiver** depuis le Play Store.
3. Ouvrez ZArchiver, allez dans votre dossier et appuyez sur le **premier fichier** (se terminant par `.001`).
4. Sélectionnez **Extraire ici**.

## 🎮 Utilisation
* **Pour le jeu :** Ouvrez votre émulateur (comme Citra) et chargez le fichier `.3ds` extrait.
* **Pour les Amiibos :** Utilisez l'option " Charger Amiibo " (Load Amiibo) de votre émulateur et sélectionnez le fichier `.bin` de votre choix lorsque le jeu vous le demande.
